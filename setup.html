Broadcast the countdown to YouTube

  1. In OBS, add a Browser source and paste your published homepage URL.
  2. Set the source dimensions to 1920 × 1080.
  3. In YouTube Studio, open Go Live and follow the streaming software instructions.
  4. Start the stream in OBS, then in YouTube Studio if prompted.

OBS sends the broadcast to YouTube; this page cannot start the broadcast by itself. Never paste your YouTube password or stream key into this website.
