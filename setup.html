Broadcast the countdown to YouTube

  1. Install and open OBS Studio.
  2. In OBS, add a Browser source.
  3. Paste your published GitHub Pages homepage URL. Set the source to 1920 × 1080.
  4. Open YouTube Studio → Create → Go live. Use YouTube's stream setup instructions in OBS.
  5. Start streaming in OBS, then start the livestream in YouTube Studio if prompted.

This website displays the countdown and embeds your stream. OBS sends the broadcast to YouTube; this page cannot start the broadcast by itself. Never paste your YouTube password or stream key into this website.
