# January 18, 2028 Countdown + Lo-fi Music
Upload all files in this folder to the root of your `jan-18-countdown` GitHub repository, replacing existing files when prompted. The new `background-music.mp3` must be beside `index.html` and `app.js`.
The countdown page has a Play Music button and volume slider. The lo-fi track loops continuously after the visitor presses Play Music. Browsers block sound autoplay until a visitor interacts with the page.
The Watch Live page also includes the music player. OBS can capture the homepage as a Browser Source; enable OBS Browser Source audio capture if you want the music in the YouTube broadcast.
